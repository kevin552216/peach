# SMB 媒体来源

Peach 通过 SMB 2/3 按账号权限直接读写网络共享。连接由运行 Peach 的机器建立；浏览器和外部播放器使用 Peach 的媒体地址，不接收 NAS 账号和密码。

## 添加目录

在「设置 → 媒体库与入库」添加文件夹，来源选择「SMB 共享」，路径填写 `smb://nas.example/Movies` 或共享内的子目录。地址不含账号、密码或查询参数。账号可填写 NAS 用户名或 `DOMAIN\username`。

填写账号和密码后点击「测试连接」。成功时可选择进入子目录，再测试该目录。「要求 SMB 加密」会拒绝不支持加密的服务器。保存配置后由应用管理入口重新加载；首次使用的目录可选择扫描并补全资料。

密码不回显，留空保留已保存的密码；更换账号时填写对应密码。「移除已保存的 SMB 账号」在保存时删除本机凭据。凭据位于数据目录的 `secrets/follow/smb-<root_id>.json`，不进入账本或配置响应。该文件不是加密保险箱，应限制数据目录的访问权限。

## 范围与限制

来源按共享账号授予的权限读写。扫描、NFO、配套图片、字幕及视频从共享读取；资料、预览和转码结果保存在 Peach 数据目录。整理和改名支持同一声明根内的移动、目录创建和整批撤回；永久删除先在同目录隔离文件，账本事务失败时恢复，提交后才清理。目标已存在时拒绝覆盖。账号没有写权限时，这些操作报告权限错误，读取照常使用。

媒体工具通过回环 HTTP Range 地址随机读取；这个供工具读取的地址只提供 GET/HEAD，不能借它写回共享。原件修复仍要求本机挂载路径，不将整部远程影片自动下载到临时目录；跨共享、跨声明根的移动不支持。

共享离线或无权读取时保留馆藏记录，不能据此断言文件已删除。直接 SMB 来源使用扫描，不加入本机文件监视。DFS 和重解析点不在支持范围；只连接明确填写的共享。每个读取句柄拥有独立连接与文件位置，请求超时关闭所属连接，恢复网络后重新发起操作。

## 配置文件

使用配置文件管理的部署，在 `[media.storage_roots.<root_id>]` 中填写 `transport = 'smb'`、`mount = 'smb://nas.example/Movies'`，保留稳定的 Windows 格式 `root` 及 `library_id`。账号文件使用 `{"username":"reader","password":"<密码>","encrypt":"true"}` 的结构，限制访问权限，不进入公开仓库。已有馆藏更换共享地址时，保留目录身份并明确选择重定位。

## 验证范围

隔离回归覆盖路径边界、期限与取消、目录元数据、配置与凭据分离、扫描字幕配对、HTTP 字节范围、整理与事务失败恢复，以及实际 FFmpeg 尾部索引及抽帧。回环临时共享另验证创建、写入、flush、改名防覆盖、读取和删除的真实 SMB 协议。真实 NAS 的认证策略、吞吐、长时间播放及断网恢复需在目标环境验证。
