# ADR-0123：SMB 媒体读写与工具输入

- 状态：已接受；真实 NAS 兼容性待验证
- 日期：2026-10-25
- 关系：补充 ADR-0021、ADR-0115

## 决策

使用 `smbprotocol==1.17.0` 按共享账号权限读写明确声明的共享。存储根目录记录 `transport = 'smb'` 与不含凭据的 `mount`；媒体库、根目录身份和账本前缀保持稳定。凭据按根目录身份单独保存到本机 CredentialStore。

显式 `SmbResource` 不实现操作系统路径协议。扫描消费目录响应元数据，解析器消费可 seek 的只读句柄；浏览器使用 Peach 鉴权下的字节范围响应。FFmpeg 和 ffprobe 使用仅监听回环地址、携带进程内随机访问凭据的 HTTP Range 入口，该入口独立于公开播放端点与 Web 服务生命周期。

传输实例独占连接，请求期限覆盖协商、认证和文件操作。超时取消并断开所属 socket。共享根固定，拒绝 DFS 与重解析点；祖先目录的共享只读句柄在子操作期间保留。写入前检查句柄类型，改名不覆盖目标、不跨声明根；整理和永久删除沿用既有事务与恢复入口。工具输入 HTTP 入口只读，原件修复不自动下载远程媒体。离线和目录读取失败不能产生文件已删除的断言。

## 取舍

独立连接会增加认证次数；连接池须另行证明单次取消不会影响其他消费者。普通管道不能提供通用随机 seek，完整暂存大文件增加等待和磁盘占用；FFmpeg 原生 SMB 依赖各平台二进制构建，因此工具输入使用 HTTP 桥。fsspec 的 SMB 封装不能替代请求取消和工具输入，未引入。

隔离回归覆盖传输、配置、扫描和实际媒体工具。真实 NAS 的兼容性与吞吐尚待目标环境验证。
