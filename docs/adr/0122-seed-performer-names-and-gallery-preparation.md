# ADR-0122：种子中文名与头像图库准备

- 状态：已接受
- 日期：2026-10-24
- 修订：ADR-0052 的自动改规范名前置条件、ADR-0075 的种子消费范围

## 背景

安装包包含已维护的中文人物名与 Gfriends 读取能力。普通扫描需要完整消费这些能力，不能依赖维护者运行本地脚本或打开换头像窗口。人物名字与头像均须保护用户选择，并能区分外部资料缺失和本次取证失败。

## 决策

种子导入对人物身份锚点、规范名、别名及站上编号取命中并集，只有唯一命中才导入。种子规范名为中文汉字、当前规范名是种子中置信度至少 0.9 的登记别名、目标名称没有被其他人物占用时，采用种子规范名。非登记自定义名称、人工选择、来源冲突和重复实体保持原样；不合并实体，不推测假名译名。

自动名称更新使用现有统一名称与作品署名同步实现，保存原名、原名称偏好、来源和时间，原名保留为别名。种子后继先在内存副本计算改名计划，有改名才用既有 SQLite 备份入口保存整本账本，再执行写事务。备份失败则任务失败。`revert_auto_landing.py` 按种子来源和批次还原仍归该批次拥有的名称快照与作品署名；后续人工选择不撤回。原名称被其他实体占用时，撤回事务失败。名称规则修订进入种子后继键，使已导入同版数据的安装也能消费名称规则。

头像自动任务和换头像接口共用应用实例内的索引刷新器，复用统一采集出口、原子缓存和失败退避。自动任务等待索引准备后再找图；窗口读取刷新状态并在当前弹层更新候选，刷新结束或失败后停止轮询。无索引且下载失败不记为已完成取证；已有索引可作为离线回退。图库内容摘要进入人物头像任务指纹，索引内容变化可使未解决的人物重新派发。索引过期时至少派一位仍需补图的人物准备索引；相同内容的保鲜刷新不整批重派。

元数据导入后的官方人物头像使用独立阶段的有界传输预算，复用代理设置、来源冷却和共享请求间隔。预算或来源暂停时停止该阶段，保留已安装图片和可重试问题。

## 验证

使用临时账本、固定来源响应和图片缓存覆盖种子匹配、规范名与署名同步、人工保护、冲突、备份、幂等与撤回。索引覆盖首次准备、失败退避、内容变化重派以及无索引失败不结算；窗口覆盖当前弹层更新及轮询终止。无需新增依赖或修改数据库结构。
