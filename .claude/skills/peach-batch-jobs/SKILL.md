# 批处理预检与续跑

最后复核：2026-10-26
证据来源：`scripts/probe.py`、`scripts/sheets.py`、流量守卫、`peach.jobs`、单机复制开关与批次事故。

## 起跑

1. 核对任务范围、真实数据授权、当前数据根与写入资格。开启复制时必须是 writer；关闭复制的独立实例按可写状态判断，不能因 `ledger_sync=disabled` 拒绝。
2. 按 `peach-ledger-write` 备份真实账本；核对迁移、目标来源可达性、已有同类任务和实时队列。代码验证按实际影响域，不因启动批次机械重跑全量。
3. 用当前来源、实际出口与采样方法估算流量和磁盘成本，批次范围、阈值与结果写仓库外运行记录，不把某晚额度或来源安排写成永久默认。
4. 按 `traffic_watch.py` 当前参数与连接计量决定是否包含直连；计费来源走直连时必须计入。不要从来源名称猜代理路径。

## 运行边界

- 运行期使用 `DiskGuard` 复查系统盘实际余量，触线停止领新任务、保存结果并保留非零退出码；不只检查产物盘或起跑余量。第三方块缓存也会占系统盘。
- `HostLimiter` 按主机限流，等待可处理其他来源；短测不能证明长跑稳定。来源反机器人与速率边界按 `docs/SOURCING.md`，不在封禁期轮换出口连打。
- 单项网络或媒体失败独立记录，允许其余任务推进；账本、结果保存等公共环节失败须中断。失败不能伪装成空结果或成功，状态数字不一致时先查遗漏状态。
- 定期持久化检查点，续跑只跳过已成功项目；限流或网络造成的暂时未取得不能冻结成永久无结果。
- 时长失败值、重探选择器、抽帧颜色重试等细节以对应脚本、`peach.media_probe` 和回归为准，不推广成所有任务通用的返回值契约。
- 接入抽帧前复用路径转换与大小写解析；色彩元数据异常仅重试失败帧，不覆盖全部输入。
- 不在真实库写入批次中切换写入端、复制账本或启动冲突批次。重启按任务恢复能力和项目授权边界执行。
- 导入运维脚本无文件、网络或数据库副作用。只停止自己拥有且命令行匹配的进程树，禁止全机终止 FFmpeg。

## 验收

取得实际退出状态，读取实时队列与日志；真实账本批次核对完整性和外键。报告完成、仍失败、待处理、是否安全中止，以及适用的流量、出口、磁盘与备份证据。触发闸门不伪报正常完成，也不为完成率提高已约定阈值。
