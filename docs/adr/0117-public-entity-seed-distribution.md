# ADR-0117：公共实体事实种子随应用分发

- 状态：已接受
- 日期：2026-10-23
- 修订：ADR-0111 的实体事实种子分发位置；保留 ADR-0073／0075／0106 的匹配、归属与纠错契约

## 背景

用户明确接受实体组合可能反映维护者馆藏，要求保留厂牌与事务所标识，并恢复种子更新路径。隐私清理中的账本、媒体、凭据和私有上下文约束仍然成立。

## 决策

公共实体种子保存于 `resources/seed/entities.json`，由维护者只读导出、复核、提交，随应用版本更新。每次更新使用递增版本与修订号，继承累计精确撤销。普通刮削不自动导出或推送；发布时携带已复核的包，用户无需额外下载器或维护一套私有种子。

种子只包含既有格式允许的公开文字事实，不包含媒体、头像、封面字节、真实账本、本机路径、敏感链接或原始刮削快照。实体组合的公开属于维护者接受的分发边界，不把其他字段的保密约束一并取消。厂牌与事务所标识继续按 ADR-0026 分发并记录来源。

运行时从源码、wheel 或 PyInstaller 共用的资源根读取种子。扫描与采集结算后自动导入，只匹配本机已有实体；保留人工与其他来源的资料归属，不创建一套维护者实体库。缺少种子的安装不能完成发行资源验收，内容损坏由格式与摘要校验拒绝。

公共种子使用明文 JSON。所有用户均需读取时，随客户端公开解密密钥无法提供有效保密性；加密不替代第三方内容的授权。私人备份可以另用私人密钥加密，但不进入公共种子分发流程。SHA-256 用于内容完整性与版本绑定，不等同于独立数字签名；来源真实性依赖既有受信发布渠道。

## 后果

应用升级携带新版包，扫描结算消费该包；维护者仍须显式刷新、核对差异和发布。没有维护者账本的 CI 只校验、打包仓库内种子，不自行采集或导出数据。Git 历史中的公开种子按公开发布物处理，不进行隐私历史清理。
