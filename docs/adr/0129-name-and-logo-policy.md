# ADR-0129：名称与标识单独成文，不改源码许可证

- 状态：已采纳
- 日期：2026-10-28
- 关系：补充 ADR-0023 第 4 阶段的许可证决定；许可证本身不变

## 背景

ADR-0023 只定了源码许可证。AGPL 约束代码的版权，不规定名称和图标怎么用，也不限制衍生版本在说明里放推广返利链接。Peach 此前没有写过名称与图标的使用条件，图标文件是否随 AGPL 授权也没有说明。

仓库已有外部贡献者，代码版权不归单一持有人。往 `LICENSE` 追加 AGPL 第 7 条附加条款，会牵涉这些贡献者的代码；「Peach」也是常见词，目前未注册商标。

## 决策

1. 名称与图标的使用条件写在 `docs/TRADEMARKS.md`，`LICENSE` 全文不改，也不作为 AGPL 附加条款。政策明确不影响任何人依 AGPL 取得的代码权利。
2. 原样分发、只做平台打包、在文章中指称以及衍生版本说明来源，都无需许可。修改后对外分发或作为网络服务提供时，须使用自己的名称和图标，并不暗示官方认可。
3. Peach 的名称、图标、官方仓库和官网不用于广告、推广返利链接或付费推荐。改名后的衍生版本在自己名下推广，不在政策约束之内。
4. 标识由 GitHub 组织 Peach（账号 `peach-mitao`）的所有者管理，并由所有者代表项目解释政策。政策按 GitHub 的组织所有者角色认定，不写个人姓名，增减所有者无需修改政策；仓库协作者与代码贡献者不因权限或贡献取得标识权利。文档与界面不使用 ™、® 符号。
5. `docs/TRADEMARKS.md` 加入 `ReleaseFilesTests` 的必备治理文件清单，README 双语许可证节链接到它。

## 后果

政策能约束的是沿用 Peach 名称或图标的版本，依靠公开声明和社区规范。GitHub 的商标投诉一般要求提供注册号，未注册的「Peach」不能借此让平台处理冒用版本；需要平台出面时，须先注册商标。改名后的衍生版本照样可以在自己的 README 里放推广，这是 AGPL 允许的。

政策只对发布之后的使用生效，已经分发的代码权利不变。之后若注册商标，或把标识转给 GitHub 组织以外的主体，另行新增 ADR 并同步 `docs/TRADEMARKS.md`。
