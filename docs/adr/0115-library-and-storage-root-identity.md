# ADR-0115：媒体库与存储根目录身份

状态：已采纳

## 背景

媒体库组织作品，存储根目录声明文件的来源、账本路径及本机挂载映射。名称可以重复或修改，目录顺序也不构成身份。多目录媒体库需要按根目录判断可达性。

## 决策

配置持久化两类独立 UUID：`media.library_catalog.<library_id>` 保存名称和图标，`media.storage_roots.<root_id>` 保存 `library_id`、`location`、`root`、`mount` 与 `cost`。一个根目录属于一个媒体库，同名媒体库保持独立。`root_id` 表示一项目录声明，不代表硬盘。

`media.locations`、`media.mounts`、路径键名称、图标及成本表是兼容投影。存在身份表时以身份表为准。扫描与路径授权继续使用平台路径解析，不维护第二套文件路径。目录重复和父子重叠在所有媒体库之间统一拒绝。

已有路径配置按原有同名分组升级。根目录 UUIDv5 的输入是规范化的账本前缀；媒体库 UUIDv5 的输入是排序后的成员前缀集合。升级结果与配置行顺序无关。配置读取不写文件；首次保存或显式升级将这些身份写入配置。持久化后修改名称、顺序与挂载映射均沿用 ID。新增媒体库使用独立 UUID，不根据名称寻找归属。

文件的稳定身份仍是 `asset.id`。根目录归属由稳定账本前缀经 `platform.resolve_root` 投影，不新增 ledger 列，也不改写既有 `asset.path`。列表使用原有资产查询与 OR 范围筛选，不关联展开多份卡片。扫描保留已有路径写法，大小写等价的路径登记到原记录；既有多行冲突停止自动处理，不盲目合并副本或个人记录。

重定位必须显式选择，保留根目录来源和账本前缀，仅更新实际挂载映射。Windows 同样执行挂载转换。添加另一目录取得新根目录身份。来源变更不能借已有根目录 ID 覆盖原归属。移除配置仅移除目录声明，文件删除和个人记录清理由各自入口负责。

来源健康摘要仅在所有根目录均离线时判整个来源离线。接口同时提供每个根目录的身份与可达性；作品播放门槛按 `root_id` 判断。扫描恢复记录绑定实际挂载位置，重定位后重新遍历并按原文件键登记。

## 升级与验证

`scripts/upgrade_media_identity.py` 默认只预演，`--apply` 排他备份原配置再原子写入。重复读取与升级保留已写入身份。它不打开 ledger；生产配置升级须由用户明确授权，账本迁移遵循独立门槛。

隔离验证覆盖旧配置分组、持久化往返、改名及重排、同名独立库、跨库重叠、目录重定位、个人记录与大小写路径登记、多根离线状态。界面使用真实小样本验收。

## 代价

路径表兼容消费者需要保持投影一致。手动修改配置应编辑身份表并重启；只修改投影不会改变目录归属。尚未持久化的旧配置应先升级再进行人工拆分，避免把名称变化解释为分组变化。
