## 适用范围

本政策中的「Peach 标识」包括：

- 名称「Peach」，用于称呼本软件或与之相似的软件时；
- 桃子图标，包括 `resources/` 下的 `peach-logo*.png`、`peach.ico`、`peach.icns`，以及应用界面和官网上的同一图形；
- GitHub 组织 Peach 的账号名 `peach-mitao` 与域名 `peach.video`。

标识由 GitHub 组织 [Peach](https://github.com/peach-mitao)（账号 `peach-mitao`）的所有者管理，并代表 Peach 项目解释本政策。「Peach」目前未注册商标。贡献代码的人对自己的贡献保留版权，但不因此取得名称和标识的权利。

## 与源码许可证的关系

源码许可证仍是 [AGPL-3.0-or-later](../LICENSE)，本政策不对代码附加限制，也不影响任何人依 AGPL 已经取得的权利。换掉名称和图标后，代码照常可以复制、修改、分发、商用或作为网络服务运行，源码提供义务按 AGPL 执行。

图标文件随源码分发，用于构建未修改的 Peach。它们的使用按本政策，不因位于仓库中就适用 AGPL。

## 无需许可的用法

- 原样分发未修改的 Peach 源码或官方发行包，保留名称与图标。
- 只为适配某个平台或软件仓库而打包、不改动功能的版本，可以沿用名称，并在说明中写明打包方。
- 在文章、教程、评测和对比中用名称指称本项目，并链接[官方仓库](https://github.com/peach-mitao/peach)。
- 衍生版本说明来源，例如「基于 Peach」「Peach 的分支」，写法不比自己的名称更醒目。

## 需要改名的情况

修改功能、界面或默认行为后对外分发，或作为网络服务提供给他人使用时：

- 使用自己的名称和图标，名称中不含「Peach」，也不使用容易混淆的写法；
- 不暗示由 Peach 项目发布、认可或赞助，例如不写「Peach 官方版」「Peach 推荐」；
- 更新检查、下载链接和问题反馈指向自己的仓库，不让使用者把衍生版本的问题报到 Peach。

## 推广与商业使用

- Peach 名称、图标、官方仓库和官网不用于广告、推广返利链接或付费推荐，也不用来让人以为 Peach 推荐了某项产品或服务。
- 衍生版本改名后在自己名下推广，属于该版本自己的事，不受本政策约束；但推广内容不能借用 Peach 的名称和图标。

## 询问与处理

拿不准的用法，在[官方仓库](https://github.com/peach-mitao/peach/issues)开 issue 询问。发现冒用时也可以在 issue 中报告，附上链接。

组织所有者可以要求不符合本政策的项目改名或移除标识。

本政策自 2026-10-28 起适用。
